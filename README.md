Entry for make.fun bounty `news-image-20261120` ($250, 50 places paid). A program that sums up 20 November 2026 world news in one image: a "One Day on Earth" world-map infographic, with each story pinned to the place it happened and a 24-hour timeline along the bottom.

`main.py` (Python 3.13, no network, deterministic) copies the bundled `news.png` (1024x1024 PNG, 320 KB) to `/output/entry.png`. Running it twice writes identical bytes.

The image covers:
- Markets in correction: AI sell-off drags the S&P 500 into correction
- Russian missiles enter Polish airspace; Kyiv bridges hit
- Mexico captures FBI most-wanted cartel boss Fausto Isidro Meza Flores
- COP31 climate talks in Antalya run past deadline over fossil fuels
- Shenzhen summit: Trump, Xi and Putin sign a joint declaration

## Run it

```sh
python3 main.py
```
